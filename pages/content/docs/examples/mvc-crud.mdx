title: mvc-crud
description: The smallest self-contained CRUD service with an OpenAPI contract.
---

`CrudApplication` constructs controller, service and in-memory repository through the regular
generated graph. `src/main/resources/openapi.json` is the contract for GET/list, POST with
201/Location and DELETE with 204.

## Run

```bash
./scripts/build.sh /abs/path/to/distribution
scripts/run-local.sh mvc-crud
curl -fsS http://127.0.0.1:8085/recipes/1
```

## Test

```bash
python3 scripts/test_mvc.py --gc-stress
python3 scripts/test_application_build.py
```

For a gateway demo grant `crud:read,crud:write`.
