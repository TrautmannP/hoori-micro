`FacadeApplication` uses the same starter and bootstrap as the HTTP examples. The injected
`OverviewService` interface sets an 800 ms method boundary with `@TaskScoped`; a shorter parent
budget still wins.

## Run & test

```bash
python3 scripts/optional_example.py build task-facade
# start registry, recipes and pantry via scripts/run-local.sh, then:
python3 scripts/optional_example.py run task-facade
curl -fsS http://127.0.0.1:8084/overview/1

python3 scripts/test_composition.py --facade
HOORI_ENGINE=interpreter python3 scripts/test_composition.py --facade
```

The module is built separately; the task processors stay on the build path and no DB
dependencies are included.
