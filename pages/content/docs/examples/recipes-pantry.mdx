## recipes-service

`controller/RecipeController` binds HTTP, `service/RecipeService` owns the operations,
`repository/RecipeRepository` is a bounded in-memory store (128 entries) and
`error/RecipeAdvice` maps errors to public codes. DTOs live in `demo-contracts`.

```bash
curl -fsS http://127.0.0.1:8081/recipes/1
curl -fsS 'http://127.0.0.1:8081/recipes?prefix=Kartoffel'
curl -i http://127.0.0.1:8081/recipes -H 'Content-Type: application/json' -d '{"title":"Möhrensuppe"}'
curl -i -X DELETE http://127.0.0.1:8081/recipes/3
```
