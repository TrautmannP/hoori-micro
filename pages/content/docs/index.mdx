Hoori Micro builds annotation-based HTTP applications on **HooriVM**:
controller → service → repository or typed service client.

<Callout type="warn" title="Experimental">
  The examples have no production authentication or data storage. The verified state is
  recorded in [`docs/validation.md`](https://github.com/TrautmannP/hoori-micro/blob/main/docs/validation.md).
</Callout>
