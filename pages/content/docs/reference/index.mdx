## Packages at a glance

| Package | Origin | Contains |
|---|---|---|
| `hoori.micro.app` | Hoori Micro | `@MicroApplication`, `@Service`, `@Repository`, `@Configuration`, `@Bean`, `@ServiceClient`, `@GatewayRoute`, `@MicroModule`, `Micro` |
| `hoori.micro` | Hoori Micro | `Microservice`, `Environment`, `Context`, `Invocation`, `ServiceCallException`, `Gateway`, `Registry`, `OpenApi` |
| `hoori.rest.mvc` | Hoori REST SDK | `@RestController`, `@RequestMapping`, `@GetMapping`…, `@PathVariable`, `@RequestParam`, `@RequestBody`, `@ResponseStatus`, `HttpResult`, `@RestControllerAdvice`, `@ExceptionHandler`, `Problem` |
| `hoori.concurrent` | Hoori SDK | `Tasks`, `TaskSpec`, `Outcome`, `Budget`, `Cancellation` |
| `hoori.tasks` | Hoori SDK | `@GenerateTasks`, `@TaskScoped`, `@Transactional` |
| `jakarta.validation` | Jakarta | `@Valid`, `@NotNull`, `@NotBlank`, `@Size`, `@Positive`, `@Min`, `@Max` |
